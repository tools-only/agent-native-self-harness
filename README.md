# Agent-native Self-Harness demo

A compact public project page introducing the quality-led, agent-owned self-harness loop and showcasing the real JPMorgan Chase Q3 2021 HTML presentation run (`gpt-6-luna`, high reasoning, OpenAI Codex OAuth).

## Contents
- `index.html`, `styles.css`, `app.js`: static product page; no build step or external assets.
- `assets/presentation.html`: delivered 15-slide deck.
- `assets/v001-contact-sheet.png`, `assets/v017-slide-15.png`, `assets/v018-slide-15.png`, `assets/v018-contact-sheet.png`: selected visual evidence.
- `components/`: the task-created reviewer, skill, validator, and quality map.

The demo run began with generic harness-learning guidance and no task-specific criteria, methods, or components preloaded. The Agent created the quality map and the three components shown here during the task. The single run demonstrates the workflow and its recorded evidence; it does not establish a causal quality gain or cross-task net benefit.

The original task material was JPMorgan Chase's publicly available Third-Quarter 2021 earnings release: https://www.sec.gov/Archives/edgar/data/19617/000001961721000446/a3q21erfexhibit991narrative.htm

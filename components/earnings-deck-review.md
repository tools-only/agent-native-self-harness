# Earnings deck review method

1. Check the brief and source text before assessing slides. Use only the supplied source for factual claims.
2. Count the slide containers and confirm the deck has exactly 15 slides.
3. On each slide with figures, verify the figure, unit, period, basis, and accounting label against the cited earnings-release section; preserve stated caveats and avoid unsupported comparisons or arithmetic implications.
4. Assess whether terms such as reserve release, managed-basis revenue, ROE/ROTCE, CET1, and AUM are explained in plain language without changing their meaning.
5. Inspect rendered previews for legibility, hierarchy, overlap, and source citations. Confirm that a user can move one slide at a time using visible buttons and keyboard controls.
6. Confirm source content is native HTML/SVG and the page is self-contained. Report any discrepancy with exact slide and source detail; otherwise record a concise pass.
